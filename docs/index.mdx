---
title: "Quick Start"
description: "Raycast is the fastest interface to get work done on your computer: a launcher where you can find apps, files, folders, windows, links, commands, AI, snippets, and more from one place. This guide walks you through a few basics to get started."
---

<Steps>
  <Step title="Search your system">
    Files, folders, and apps are searchable directly from Root Search. Press your Raycast hotkey, start typing, and select something you use often without opening Finder or File Explorer.

    Read the <Icon icon="folder" color="#F43F5E" /> File Search page for more information.
  </Step>
  <Step title="Use the action panel">
    The Action Panel unlocks much of what Raycast can do. With an app, file, folder, command, or search result selected, press <kbd>⌘K</kbd> / <kbd>CtrlK</kbd>. From here, you can discover every action available for the selected item.

    Read the  <u>Action Panel page</u> for more information.
  </Step>
</Steps>
